# BankingApp (iOS SwiftUI)

Это пример полнофункционального банковского приложения для iOS, написанный на SwiftUI 5 / iOS 17. 

## Основные возможности
- Лента с балансами, быстрыми действиями, последними операциями и финансовой аналитикой
- Детальные экраны счетов, карт и платежей
- Переводы между собственными и внешними счетами
- Оплата регулярных счетов и сохраненных получателей
- Управление картами (виртуальные/физические, лимиты, блокировка)
- Профиль пользователя с настройками безопасности и поддержкой

## Как собрать
1. Создайте новый SwiftUI App в Xcode с именем `BankingApp` (iOS 17)
2. Замените автоматически созданные файлы содержимым из папки `BankingApp`
3. Убедитесь, что папки `Models`, `Services`, `ViewModels`, `Views` добавлены в таргет
4. Запустите проект на симуляторе iPhone 15 Pro (или любом iOS 17+ устройстве)

## Архитектура
- **Models** — структуры данных (счета, карты, транзакции, счета на оплату, получатели)
- **Services** — слой бизнес-логики и моковых данных (`BankingService`)
- **ViewModels** — ObservableObject-слой для экранов
- **Views** — SwiftUI интерфейсы и переиспользуемые компоненты

Каждый экран использует EnvironmentObject `BankingService` или конкретные ViewModel’и для управления состоянием и бизнес-процессами.
